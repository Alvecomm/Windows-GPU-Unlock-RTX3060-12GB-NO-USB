# Supporting This Project

This project is free and open source. It exists to make full-rate tensor performance on
GeForce RTX 3060 cards usable on Windows without a USB stick, with safety checks first.

## GitHub Sponsors (Recommended)

👉 https://github.com/sponsors/Alvecomm

GitHub Sponsors supports monthly contributions, starting as low as **$1/month**. It helps
test more hardware, maintain the tools and keep the documentation accurate.
There are no gated features or paywalls. Support is optional and always appreciated.

## Other ways to support

- Star the repository and share it with people who may benefit
- Report your results (logs without personal data) in Issues
- Provide feedback or suggestions

## Upstream

This work builds on [Zagitta/gpu-unlock](https://github.com/Zagitta/gpu-unlock) and
[windows-GPU-UNLOCK/Windows-GPU-UNLOCK](https://github.com/windows-GPU-UNLOCK/Windows-GPU-UNLOCK).
Please consider supporting their authors too.

## Transparency

All sponsorships go toward open-source work under the Alvecomm organization.
This project will remain open source regardless of sponsorship level.
